M1 · Motion Principles
PurposefulEvery animation communicates a state change — never decorative
SwiftMost transitions 150–300ms. Users should never wait for animation.
NaturalSpring curves for physical feel. Linear only for continuous rotation.
ConsistentSame action = same animation everywhere. Predictability builds trust.
When to Animate
Animate to show spatial relationships (where did it come from, where is it going).
Animate to provide feedback (tap → response, submit → confirmation).
Animate to guide attention (new content, error state, success).
Never animate for decoration. No bouncing logos, no spinning icons.
Never animate loading spinners faster than 1s per revolution — it causes anxiety.

M12 · Reduced Motion
Detectionprefers-reduced-motion: reduce media query
BehaviorAll transitions become instant (0ms) or fade-only
例外Spinners and progress indicators keep animation
CSS Implementation
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}

M13 · Haptic Feedback
Impact LightButton tap, toggle switch, segment selection
Impact MediumToggle on/off, Stepper change, Drag start
Impact HeavyPull-to-refresh threshold, Swipe dismiss
SelectionPicker scroll, Tab switch, Segment scroll
Notification SuccessTransfer complete, Payment sent, Goal reached
Notification WarningLow balance, Bill due soon
Notification ErrorTransfer failed, Authentication error
Haptic + Visual Pairing
Haptics always accompany visual feedback — never standalone.
Light impact for routine actions, heavy for significant moments.
Success haptics for financial milestones (goal reached, large transfer).
Never use error haptics for non-error states.
M14 · Figma-Importable Tokenstokens.studio format
How to Import
Step 1Install Tokens Studio plugin in Figma
Step 2Open plugin → Import → JSON file
Step 3Select motion.json → Import
Step 4Tokens appear as variables in Figma
Step 5Apply to prototyping animations in Figma
Token Structure
// Advizmo/Motion — tokens.studio format
{
  "duration": {
    "instant": { "value": "100ms", "type": "duration" },
    "fast": { "value": "150ms", "type": "duration" },
    "normal": { "value": "200ms", "type": "duration" },
    "standard": { "value": "250ms", "type": "duration" },
    "slow": { "value": "300ms", "type": "duration" },
    "slower": { "value": "400ms", "type": "duration" },
    "page": { "value": "500ms", "type": "duration" }
  },
  "easing": {
    "standard": { "value": "cubic-bezier(0.4, 0, 0.2, 1)" },
    "entrance": { "value": "cubic-bezier(0, 0, 0.2, 1)" },
    "exit": { "value": "cubic-bezier(0.4, 0, 1, 1)" },
    "spring": { "value": "cubic-bezier(0.34, 1.56, 0.64, 1)" },
    "bounce": { "value": "cubic-bezier(0.68, -0.6, 0.32, 1.6)" },
    "smooth": { "value": "cubic-bezier(0.25, 0.1, 0.25, 1)" }
  },
  "enter": { /* 7 enter animations */ },
  "exit": { /* 4 exit animations */ },
  "state": { /* hover, pressed, focus, disabled */ },
  "data": { /* valueChange, barGrow, lineDraw, counter */ },
  "page": { /* push, pop, modal, sheet */ },
  "gesture": { /* pullRefresh, swipeDismiss, dragScroll */ },
  "micro": { /* toggle, checkbox, like, bookmark, toast, spinner */ },
  "notification": { /* banner, badge, dot */ }
}
